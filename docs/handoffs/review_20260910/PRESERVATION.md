# 结果保护边界与有限验证

## 必须保持

| 部分 | 结构重构不能改变的内容 |
|---|---|
| Section 1 | 文件/帧顺序、两个 repeat 边界、raw/postproc 对应、single U/V、logical 有效掩膜、去壁行/坐标方向、mm 与 m 单位、缓存字段及分块读取 |
| Section 2 | repeat 时均和总体矩口径、有效点、帧范围、均值/应力/RMS/TKE；传统与现代 Clauser 的参数、平滑、厚度和 Cf；剖面区间、u_tau 来源与图形效果 |
| Section 3 | 原相位箱/相位零点约定；剖面和云图的数据源、原三重分解口径；已调好的布局、5点显示平滑、marker 与导出名；baseline 默认跳过 |
| Section 4 | 正式 PostProc + POD-E50 链；均值/RMS 来源、重建秩、8/4邻域、正负阈值、严格长度判据、掩膜、边缘剔除、完整结构/非重叠筛选、图形与选择规则；保留大数据分块策略 |
| Section 5 | raw 默认与整体 postproc 切换；同源同样本、每 repeat 独立分解；总=相干+随机；共同均值梯度的主剪切生产项；H 严格大于、符号/概率分母/缺测行为；case 独立 6/15 图 |

图形保护不只是 PNG 数量，也包括数据层、坐标/归一化、色标、布局、曲线和选帧规则。导出时间戳、绝对路径与图文件内部元数据可以因移动发生变化，不要求这些内容逐字节相同。

## 不能借重构混入的科学更改

Section 5 修复了同源/逐 repeat/有效样本问题，刻意没有改 Section 1–4。Section 2/3 的旧结果与 Section 5 不一定相同。未来若发现 repeat_means 有效性、相位计数分母等科学问题，列为独立科学修正提案，展示差异，不能悄悄“统一”。

Section 4 baseline 原存导出比当前逻辑旧。保真比较必须标明是比较原产物，还是在同一份代码/参数上重跑得到的参考；不得把旧图片差异当作此次回归。

Section 5 云图的极值使用 99.5% 分位色限，CSV 保留全范围/截断数。显示弱、空白与真零不等价；独立色标的相干细节图不能凭色深和总量比较。

## 验证要有边界

1. 结构移动优先保持数学核心不动，旧/新实现用同一份小样本比较关键数组、掩膜和对象筛选。
2. 浮点运算顺序未变时应保持原值；平台或线性代数实现差异可用明确小容差，不能靠放宽容差掩盖算法变化。POD 特征向量符号不是物理差异，应比较重建/子空间而非裸符号。
3. 小样本只覆盖接口、局部数值和实现变化；正式统计、POD rank/超结构目录与图组最终保真在本地有原数据时做一次相关部分对照。不每次从 Section 1 全量跑起。
4. 没有改动/失败/新疑点，不追加循环验证。只有实质 I/O 与数据错误需要直接报错，不用通用恢复系统把异常变成默认结果。

`full_run_reference.mat` 与 reference_outputs 是原结果观察锚点；`smoke_expected.mat` 是当前代码在明确缩小配置下的参考，二者用途不同。ZIP 清单的 SHA-256 只用于一次性交接完整性，不是给主程序新增运行期哈希校核。
