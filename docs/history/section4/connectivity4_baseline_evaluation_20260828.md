### 1.3 性能下降原因分析

**理论解释（渗流分析）：**

```
connectivity=8 (对角连通):
- 临界占据率 p_c ≈ 0.407
- alpha=0.40 → 占据率 ≈ 0.41
- 状态：恰好超过临界点，大量连通

connectivity=4 (正交连通):
- 临界占据率 p_c ≈ 0.593
- alpha=0.40 → 占据率 ≈ 0.41
- 状态：远低于临界点，大量孤立碎片
```

**物理解释：**
- 四邻域不允许对角连接
- 原本通过对角桥接的弱连通区域被切断
- 断裂后每段长度可能 <3×δ99，被过滤

**示例：**
```
O O O    connectivity=8: 一个连通域
 O O     connectivity=4: 两个孤立域（对角不连）
```

## 三、预期性能

### 3.1 merge_gap 优化效果预测

**基于 connectivity=8 的经验：**
- merge_gap: 0 → 8，检出率提升 2%（95.4% → 97.2%）
- merge_gap: 0 → 8，VLSM 数提升 33%（135 → 180）

**connectivity=4 预测：**
- merge_gap: 0 → 12，检出率提升 15-20%（72% → 87-92%）
- merge_gap: 0 → 12，VLSM 数提升 40-50%（99 → 139-149）

**理由：**
- connectivity=4 断裂更严重，merge_gap 改善空间更大
- 但绝对性能仍可能低于 connectivity=8
