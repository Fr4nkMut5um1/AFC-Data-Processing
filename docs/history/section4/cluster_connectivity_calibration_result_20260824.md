## 2. 转变区定位

- 转变区标志: 最大簇占比 A_max/ΣA 谷值位置
- **转变区 alpha: 0.60**（最大簇占比最小值位置）

## 10. 双机制改进（2026-08-24 后续）

### 问题

在 α=1.77 / seed_alpha=1.97 参数下，12000 帧中检出 0 个 VLSM。通过人工判例（第 11627 帧）确认：
- 蓝色低速结构（x≈30–150mm, Lx≈120mm≈3.75δ）的翼部幅值仅 ~0.67σ，被 α=1.77 切断
- 红色高速结构（x≈100–250mm, Lx≈150mm≈4.7δ）peak 仅 ~1.0–1.7σ，低于 seed_alpha=1.97，完全漏检

### 定量分析

在 y≈20–25mm（y/δ≈0.6–0.8）处，u_rms ≈ 1.5 m/s。附图中淡蓝区域 |u'| ≈ 1 m/s → 归一化 ≈ 0.67σ。

### 改进方案

双机制组合：宽滞回 + 流向近邻合并

| 参数 | 旧值 | 新值 | 物理依据 |
|------|------|------|----------|
| alpha (growth) | 1.77 | 0.67 | 刚好覆盖结构翼部；单侧占据率~25%，远低于4连通逾渗临界~59% |
| seed_alpha | 1.97 | 1.5 | 使中等强度结构 peak 可成为核心 |
| merge_gap_cells | — | 40 | ~20mm ≈ 0.6δ，桥接流向断裂带 |
| merge_require_y_overlap | — | true | 防止垂直不相关结构被合并 |

### 合并算法

1. 按符号分组，每组内按 XMin 排序
2. 滑动窗口检测相邻结构 gap ≤ 40 cells 且 y 范围重叠
3. Union-find 处理传递链
4. 合并后重算几何和 LSM/VLSM 分类

### 验证

Phase C 扫描 merge_gap_cells ∈ [0, 10, 20, 30, 40, 50, 60]，在固定 alpha=0.67 / seed=1.5 下确认：
- VLSM 检出数从 0 变为非零
- 最大结构不会穿透整个 FOV
- 运行 `tools/run_r2_wide_percolation_sweep.m` Phase C 可复现
