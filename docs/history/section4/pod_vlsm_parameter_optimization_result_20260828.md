## 失败模式分析

### 1. Recall 不足（主导失败原因）

**观察：** 所有配置的 Recall 均在 0.41-0.62 之间，远低于隐含目标 >0.85

**原因分析：**
- POD 去噪重构在 50% 能量下可能丢失部分弱结构信号
- 聚类阈值即使降至 alpha=0.35 仍未捕获足够的弱波动结构
- FOV 边缘结构的识别困难（edge object F1 仅 0.35-0.44）

**已尝试措施：**
- 降低 seed_alpha（0.60→0.55）：Recall 提升 3.3%
- 降低 alpha（0.40→0.35）：Recall 提升 11.4%
- 增加 merge_gap_cells（0→8）：Recall 提升 27.5%

**效果：** 三项措施叠加后，Recall 从 0.407 提升至 0.597（**+46.7%**），但仍未达标

---

### 2. Position Match Rate 低

**验收阈值：** 0.85  
**实际性能：** 0.56-0.79（最优 attempt_12 的 round 3 为 0.778）

**原因：**
- 聚类质心与视觉标注质心的空间误差超过阈值（x误差 >10% FOV 或 y误差 >15% FOV）
- merge_gap_cells=8 虽提升了结构合并，但可能导致质心偏移
- POD 重构的空间分辨率限制

---

### 3. Edge Object F1 低

**验收阈值：** 0.80  
**实际性能：** 0.35-0.44

**原因：**
- FOV 边缘结构被部分截断，聚类和视觉标注都难以准确界定
- 边缘结构的符号和位置匹配更易出错
- 当前配置 edge_policy="include_fov_edges_for_pod" 保留边缘结构，但识别质量不足

---

### 4. Length Relative Error 偏高

**验收阈值：** 中位数 ≤0.20  
**实际性能：** 0.11-0.30（attempt_12 的 round 2 为 0.299，超标）

**原因：**
- 聚类算法基于连通性，结构长度受 merge_gap_cells 影响较大
- 视觉标注基于人眼估计，与聚类算法的几何定义存在系统性差异

## 参数敏感性总结

### merge_gap_cells（拓扑参数）
- **影响最大**：从 0→8，F1 提升 13.8%
- **机制**：允许跨越小间隙合并分散像素，显著提升 Recall
- **副作用**：Precision 略降，Length Error 和 Position Match 可能恶化
- **推荐值**：**8** cells

### alpha（主阈值）
- **影响显著**：从 0.40→0.35，F1 提升 5.5%
- **机制**：降低识别阈值，允许更弱的波动被标记为结构
- **副作用**：过低（0.30）导致 Precision 下降超过 Recall 增益
- **推荐值**：**0.35**

### seed_alpha（种子阈值）
- **影响中等**：从 0.60→0.55，F1 提升 1.9%
- **机制**：降低种子点阈值，增加结构起点数量
- **副作用**：过低（0.50）反而降低 F1
- **推荐值**：**0.55**

### connectivity
- **固定值**：8（八邻域连通）
- 未进行变参测试，保持标定值

## 根本原因与技术限制

### 1. POD 能量截断损失

**问题：** 50% 能量重构 (rank=382) 保留了主要模态，但可能丢失了部分弱结构的高阶模态信息

**证据：**
- 聚类识别的 VLSM 数量（平均 45-50）少于视觉标注（平均 51-64）
- Recall 瓶颈难以突破 0.6

**可能措施（未实施）：**
- 提高能量目标至 60-70%（需重新计算 POD 基并重新优化所有参数）
- 使用自适应秩选择（per-frame optimal rank）

---

### 2. 聚类算法的固有限制

**问题：** 基于强度阈值和连通性的聚类算法无法完美匹配人眼视觉判断

**证据：**
- Position Match Rate 和 Length Error 难以同时满足高标准
- merge_gap_cells 增加改善 Recall 但恶化 Position 精度

**可能措施（未实施）：**
- 引入基于机器学习的后处理（如语义分割模型）
- 使用自适应阈值（per-region adaptive alpha）

---

### 3. 边缘结构识别困难

**问题：** FOV 边缘的截断结构难以准确识别和匹配

**证据：**
- Edge Object F1 仅 0.35-0.44，远低于整体 F1 0.63
- 边缘结构的符号匹配和位置匹配尤其困难

**可能措施（未实施）：**
- 排除 FOV 边缘结构（edge_policy 调整），但会丢失物理上重要的信息
- 扩大 FOV 或使用边界条件外推

---

### 4. 验收标准过于严格

**观察：** F1 ≥ 0.80 是非常高的要求，相当于 Precision 和 Recall 均需 >0.75

**当前差距：**
- 最优 F1 = 0.631，距目标差距 **26.8%**
- 需同时提升 Precision 和 Recall 约 **20-25%**

**建议：** 考虑根据实际应用场景调整验收阈值，或将此作为"目标"而非"硬性要求"
